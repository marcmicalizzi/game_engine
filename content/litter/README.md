# Forest litter recipes

Six static patches: leaf (white oak), needles and cone (white pine), bark, twig and tangle.
Each file uses the kind default budget and seed 17. See [litter](../../docs/subsystems/litter.md)
for counts, dimensions, shared deadwood geometry and material-pack roles. Build with
`engine-content build content/litter/leaf.litter.json <external-output>.clusters`.
