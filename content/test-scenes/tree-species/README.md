# Tree species gallery

Ten representative species in two rows, 25 m between trees. From left to right the front row is
maple, oak, elm, walnut and beech; the rear row is ash, pine, spruce, cedar and juniper. The recipes
are in [the species folder](../../flora/species/README.md). Use an elevated view for silhouettes and
then approach the cedar and oak for root flare and branch collars. The flat colours deliberately
make this a geometry inspection; species textures are separate material-pack work.

Run `engine-view --scene content/test-scenes/tree-species/scene.json`. Captures and benchmarks are
local artifacts, not committed images. The dwelling-tree fixture is separate so a giant crown does
not obscure this comparison. See [growth rules](../../../docs/experiments/tree-growth-rules.md)
for the measurements and remaining visual limitations.
