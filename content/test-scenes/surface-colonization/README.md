# Surface colonization

G124's static comparison: two granite hosts (crevice moss and exposed siliceous lichen), and
a decaying oak log with fungi and small establishing plants. No external kit is required.
`scene.json` places each host and companion with the same translation and no independent fitting.
Build through engine-view's normal mesh registry, or `engine-content cover` for each recipe.

Suggested offscreen review: the gallery from 5, 20 and 60 m, then separate close views of the
rock's sheltered foot and the log's top. Capture commands, cameras, containers and measured
results belong under `D:/workspace/game_engine_local/surface-colonization/2026-11-04/`.
The [grounding page](../../../docs/experiments/surface-colonization.md) records validation and
limitations. The active forest POC is read-only and is not modified by this gallery.
