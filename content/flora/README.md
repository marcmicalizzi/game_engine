# Flora recipes

Source recipes for the flora mesh generator. See [flora](../../docs/subsystems/flora.md).

## Ground plants (G103)

The new opt-in recipes are `fern-arching`, `fern-autumn`, `fern-creeping`, `hosta-rosette`,
`hosta-flowering`, `hosta-autumn` and `plantain-rosette`. Existing recipes keep their shapes.
Hosta and plantain are botanical habit examples, not exact species reconstructions; the creeping
fern has a polypody-inspired rhizome layout but retains the fern solver's separate pinna cards.
[Grounding](../../docs/experiments/ground-plants.md) lists dimensions and approximation limits.
Each recipe explicitly keeps the existing 4,000 fern / 2,500 herb triangle ceiling. Seasonal
states are authored static examples. [The review scene](../test-scenes/ground-plants/README.md)
stands each form in a row, with groups behind it to expose repetition.
