# Age-enabled tree examples

Four additions to the shared species catalogue. `aspen` and `alder` are quaking aspen and western
red alder; `fir` and `hemlock` are balsam fir and eastern hemlock. Each uses the same seed, ordinary
site quality and somewhat open space. Hemlock is 400 years old; the others are 60, deliberately
different developmental stages. Copy a recipe and set `tree.age_years` to 1, 5, 30 or an appropriate
old age, with size overrides zero, to inspect development. See
[flora maturity](../../../docs/subsystems/flora.md#species-maturity) for size override semantics,
legacy recipes, source ranges and the distinction between age, space, site and vitality.
