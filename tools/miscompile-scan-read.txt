# Sites tools/miscompile-scan.ps1 reports that have been read and are not the compiler's fault
# (docs/experiments/msvc-ob2-avx2-miscompile.md, "Reading a candidate"), and the one that is the
# fault on purpose. One line a site:
#
#   <unit, or * for any> <place> <callee, or its start and a *> : <why>
#
# <place> is where the address travels (rcx, rdx, r8, r9, stack), as the report prints it. A line
# needs its reason, and the scan says when a line matches nothing any more: remove it then. A site
# is added here only after its listing was read, never to make a run pass.
