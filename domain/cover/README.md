# Cover

Static host-surface companions: ivy, moss, lichen, algae, wood fungi and nurse-log establishment.
The [subsystem page](../../docs/subsystems/cover.md) describes the contract, budgets and tests.
`schemas/cover.schema` owns ecological inputs; `src/habitat.cpp` resolves local substrate regions.
Geometry and exposure are shared with the original solvers. Growth remains content-time work.
