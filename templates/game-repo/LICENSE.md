# Licence

**This repository's licence is its author's to choose, and this file is where the choice goes.**
Nothing here is licensed until it is replaced.

What the engine side is: the SDK this game builds against (`engine-sdk.json`) carries headers,
binaries and content of the engine under the Apache License 2.0; a game built with the engine owes
attribution (the engine's `NOTICE`) and nothing else, whatever licence the game itself takes.

What the engine's own reference game chose, as one worked example and not a recommendation: Desert
Survival's code is GPL-3.0-or-later, its assets are CC BY-NC-SA 4.0 or all rights reserved with a
grant of personal use, and its title is a trademark, so that the game stays readable and buildable
as a reference while a low-effort clone cannot be sold. The reasoning is the engine's ADR-0047
(`docs/adr/0047-reference-games-are-licensed-apart-from-the-engine.md` at the pinned commit).

Whatever is chosen: say it here, put the licence text beside this file, and record each asset's
grant where the asset is.
