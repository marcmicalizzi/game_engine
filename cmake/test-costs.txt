# Seconds per test source file, which a parted test's files are dealt by (roadmap T77, T88;
# docs/ci/what-to-run.md, "Parts dealt by cost"; engine_deal_test_files in
# cmake/EngineTestDeal.cmake).
#
#   <test> <basename> <whole seconds>  # <where the number came from>
#
# <test> is the CTest name before its part number (renderer, gfx, engine_view), <basename> a source
# file of its executable, the seconds its cases took in the slowest of the measured runs, and the
# comment that run's label. A file this table does not name is dealt by name order after the ones
# it does, so an empty table is the name-order deal.
#
# The slowest card is the binding one: a part that fits on the GPU server (the Titan Xp,
# `tools/remote-build.ps1 -Preset linux-server -Test -Fetch <dir>`) fits on the RTX 5090. Written by
#
#   tools/test-costs.ps1 -Log <server LastTest.log>,<msvc-release LastTest.log>,...
#                        -Tests renderer,gfx,engine_view -BuildDir build/msvc-debug
#
# from a gate's logs (every module and end-to-end test runs with doctest's `--duration=true` since
# T77), and checked before it is committed with `tools/test-costs.ps1 -Predict -BuildDir
# build/msvc-debug -Table <the new table>`, each part's seconds as dealt now and as the table deals.
# Empty on purpose until the merged tree of 2026-11-11 is re-dealt: gate b58's logs give the first
# rows, and the rows other branches' new test files need land with that re-deal.
