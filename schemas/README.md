# Schemas

Single source of truth for every serialized or transmitted type: document object types, protocol messages, world events, components, asset provenance. Code for C++, JSON (de)serialization, JSON Schema, protocol documentation, MCP tool definitions, and migration stubs is generated from these files and never hand-edited.

The IDL and generator arrive in Phase 0 (docs/plan/10-roadmap-risks.md). Until then this directory holds only this note.
